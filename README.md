# joketeller

A minimal command‑line program that prints a random joke.

## Features
- No external dependencies – uses only the Python standard library.
- Works on any platform with Python 3.8+.
- Simple, well‑typed code with clear error messages.

## Installation
```bash
# Clone the repository
git clone https://github.com/your‑username/joketeller.git
cd joketeller
```

No additional packages are required.

## Usage
```bash
python joketeller.py
```
The script will contact the free **JokeAPI** and display a single‑line joke.
